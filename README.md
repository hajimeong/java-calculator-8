# java-calculator-precourse

## 문자열 덧셈 계산기
쉼표(,)또는 콜론(:) 및 커스텀 구분자로 가지는 문자열에서 
구분자를 기준으로 숫자를 추출해 각 숫자의 합을 구하는 계산기


## 구현 기능
1. 사용자로부터 문자열 입력 받음
    ```text
    덧셈할 문자열을 입력해 주세요.
    ```
2. 입력받은 문자열로부터 커스텀 구분자 추출 및 구분자 기준으로 문자열 분리
   - 커스텀 구분자가 정의되어 있지 않은 경우
     - 기본 구분자가 아닌 문자가 있는가 검증
     - 사용자의 입력 숫자가 음수가 있는지 검증
   - 커스텀 구분자가 정의되어 있는 경우
     - 커스텀 구분자 정의 형태에 알맞는 형태인지 검증
     - 커스텀 구분자가 숫자이지는 않은지 검증
3. 분리된 문자열은 숫자로 변환
4. 변환된 숫자들의 합 계산
5. 결과 출력
    ```text
    결과: {결과값}
    ```
   
### 예외처리
조건에 맞지 않는 입력이 들어올 경우 IllegalArgumentException을 발생시킨 후
애플리케이션 종료
